== Custom Types

Dueuno supports a set of built-in types such as strings, numbers, dates and
lists. Applications can also define their own types when a value has a meaning
that cannot be represented adequately by a primitive value.

A `CustomType` is a domain value that participates in Dueuno's typed-value
protocol. It knows how to:

* identify itself with a unique type name;
* serialise itself before it is sent to the browser;
* restore itself from the value submitted by the browser;
* render a human-readable representation.

The type name is supplied by the `getTypeName()` method. The optional metadata
methods `getTypeField()`, `getValuePropertyType()` and
`getValuePropertyName()` can be overridden when the type has a dedicated field
or must be inspected by the database explorer.

The type must be registered once during application startup. Registration lets
`Types` create the correct object when it receives a typed value from the
browser.

=== Shipping option

Wrapping a single enum in a `CustomType` would add little value because Dueuno
already supports enums natively. A more useful example is a shipping option:
the user chooses a shipping method, while the application also needs the
associated cost and delivery time.

.Create `~/demo/src/main/groovy/com/example/ShippingMethod.groovy`
[source,groovy,subs="attributes+"]
----
package com.example

enum ShippingMethod {
    STANDARD,
    EXPRESS,
    PICKUP,
}
----

The `ShippingOption` class wraps the enum and adds the information associated
with the selected method. The wire format used in this example is:

[source,json]
----
{
    "type": "SHIPPING_OPTION",
    "value": {
        "method": "EXPRESS",
        "cost": 9.90,
        "deliveryDays": 1
    }
}
----

.Create `~/demo/src/main/groovy/com/example/ShippingOption.groovy`
[source,groovy,subs="attributes+"]
----
package com.example

import dueuno.elements.core.PrettyPrinterProperties
import dueuno.elements.core.PrettyPrinter
import dueuno.types.CustomType

class ShippingOption implements CustomType {

    ShippingMethod method
    BigDecimal cost
    Integer deliveryDays

    ShippingOption() {
    }

    ShippingOption(ShippingMethod method, BigDecimal cost, Integer deliveryDays) {
        this.method = method
        this.cost = cost
        this.deliveryDays = deliveryDays
    }

    static ShippingOption forMethod(ShippingMethod method) {
        switch (method) {
            case ShippingMethod.STANDARD:
                return new ShippingOption(method, 4.90, 3)
            case ShippingMethod.EXPRESS:
                return new ShippingOption(method, 9.90, 1)
            case ShippingMethod.PICKUP:
                return new ShippingOption(method, 0.00, 0)
            default:
                return null
        }
    }

    String getTypeName() {
        return 'SHIPPING_OPTION'
    }

    Class getTypeField() {
        return ShippingOptionField
    }

    Class getValuePropertyType() {
        return ShippingMethod
    }

    String getValuePropertyName() {
        return 'method'
    }

    Map serialize() {
        return [
            type : typeName,
            value: [
                method      : method?.name(),
                cost        : cost,
                deliveryDays: deliveryDays,
            ],
        ]
    }

    void deserialize(Map valueMap) {
        if (!valueMap.value) {
            return
        }

        if (valueMap.value in Map) {
            Map value = valueMap.value as Map
            method = value.method ? ShippingMethod.valueOf(value.method as String) : null
            cost = value.cost as BigDecimal
            deliveryDays = value.deliveryDays as Integer
            return
        }

        ShippingOption option = forMethod(ShippingMethod.valueOf(valueMap.value as String))
        method = option.method
        cost = option.cost
        deliveryDays = option.deliveryDays
    }

    String prettyPrint(PrettyPrinterProperties properties) {
        if (!method) {
            return ''
        }

        PrettyPrinterProperties renderProperties = new PrettyPrinterProperties()
        renderProperties.locale = properties.locale
        renderProperties.textPrefix = 'shipping.method'
        return PrettyPrinter.printString(method.name(), renderProperties)
    }
}
----

The no-argument constructor is required because `Types` creates an empty
instance during registration and deserialisation. The `serialize()` method
converts the enum to its stable name and includes the related shipping data,
while `deserialize()` restores the complete object. The
`shipping.method.STANDARD`, `shipping.method.EXPRESS` and
`shipping.method.PICKUP` messages can be defined in the application's message
bundle to control the text displayed to users. For example:

[source,properties]
----
shipping.method.STANDARD=Standard delivery
shipping.method.EXPRESS=Express delivery
shipping.method.PICKUP=Pick up at the store
----

=== Field

`Select` already knows how to build its options from an enum. The custom field
only has to provide the enum class and the custom type name. The selected method
can then be used to calculate or load the remaining shipping data.

.Create `~/demo/src/main/groovy/com/example/ShippingOptionField.groovy`
[source,groovy,subs="attributes+"]
----
package com.example

import dueuno.elements.controls.Select
import dueuno.elements.core.Elements
import dueuno.types.Types

class ShippingOptionField extends Select {

    ShippingOptionField(Map args) {
        super((args ?: [:]) + [
            optionsFromEnum: ShippingMethod,
            valueType: Types.getTypeName(ShippingOption),
        ])
    }

    @Override
    void setValue(Object value) {
        super.setValue(value instanceof ShippingOption ? (value as ShippingOption).method.name() : value)
    }

    @Override
    String getValueAsJSON() {
        ShippingMethod method = value ? ShippingMethod.valueOf(value as String) : null
        ShippingOption option = method ? ShippingOption.forMethod(method) : null
        return Elements.encodeAsJSON(Types.serializeValue(option, Types.getTypeName(ShippingOption)))
    }
}
----

`ShippingOptionField` renders the three enum constants as selectable options.
Since its `valueType` is `SHIPPING_OPTION`, the selected value is serialised as
a `ShippingOption` object instead of as a plain string. The field converts an
existing `ShippingOption` to its method for display and rebuilds the complete
object when the selection is serialised.

=== Usage

Register the class during application startup, together with the other custom
types used by the application.

.Edit `~/demo/grails-app/init/BootStrap.groovy`
[source,groovy,subs="attributes+"]
----
import com.example.ShippingOption
import dueuno.types.Types

class BootStrap {

    def init = {
        Types.register(ShippingOption)
    }
}
----

The field can now be used in a form like any other Dueuno field:

[source,groovy,subs="attributes+"]
----
form.addField(
    class: ShippingOptionField,
    id: 'shipping',
    label: 'Shipping method',
    value: new ShippingOption(ShippingMethod.EXPRESS, 9.90, 1),
)
----


When the form is displayed, the user chooses a shipping method from the
`Select`. On submission, `Types` sees the `SHIPPING_OPTION` type name, creates a
`ShippingOption` instance and calls `deserialize()`. Application code can
therefore work with the strongly typed value:

[source,groovy]
----
ShippingOption shipping = params.shipping
assert shipping.method == ShippingMethod.EXPRESS
assert shipping.cost == 9.90
assert shipping.deliveryDays == 1
----

This separation keeps the user interface responsible only for choosing an
option, while the domain code receives a meaningful object with an explicit
value, serialisation format and display behaviour.
